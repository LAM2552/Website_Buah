# Latihan React Base

Proyek React dasar menggunakan Vite.

## Perintah umum

Install dependensi:

```bash
npm install
```

Jalankan dev server:

```bash
npm run dev
```

Build produksi:

```bash
npm run build
```

Lint dan format:

```bash
npm run lint
npm run format
```

Jalankan test:

```bash
npm run test
```
